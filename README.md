# 404 ERP

## Visão Geral

**404 ERP** é um sistema de gestão empresarial (Enterprise Resource Planning) modular, web-based, desenvolvido especificamente para atender as necessidades de pequenas e médias empresas (PMEs). O projeto busca fornecer uma solução integrada e escalável para automação de processos empresariais.

## Objetivo

Centralizar a gestão de clientes, fornecedores, produtos, estoque, compras, vendas, financeiro e prover insights através de dashboards e relatórios, com segurança, performance e usabilidade em foco.

## Stack Tecnológica

### Backend
- **Runtime**: Java
- **Framework**: Spring Boot
- **Autenticação**: Spring Security + JWT
- **Build**: Maven

### Frontend
- **Framework**: Vue 3
- **Linguagem**: TypeScript

### Banco de Dados
- **SGBD**: PostgreSQL
- **ORM**: JPA / Hibernate

### Comunicação
- **Protocolo**: REST API

### Infraestrutura
- **Containerização**: Docker
- **Versionamento**: Git + GitHub

## Módulos Planejados

- Autenticação e Segurança
- Usuários
- Clientes
- Fornecedores
- Produtos
- Estoque
- Compras
- Vendas
- Financeiro
- Dashboard
- Relatórios
